## 2. Юнит-экономика: сколько стоит посетитель

Это число определяет всё в платной части, поэтому считаем явно.

**Средний чек:** $206 / 7 = **$29**

**LTV с поправкой на подписки.** Из семи покупок три разовые ($4, $4, $12),
четыре — подписки ($9/мес ×2, $69/год, $99/год). Если месячная живёт в среднем
5 месяцев:

```
(4 + 4 + 12 + 45 + 45 + 69 + 99) / 7 ≈ $40 на покупку
```

**Доход с тысячи читателей:** 0.31% × 1000 × $40 ≈ **$124**, то есть
**12 центов с посетителя**.

**Доход с одной регистрации:** 4 покупки на 31 регистрацию = 12.9%, × $40 ≈
**$5.2 за регистрацию**.

### Что из этого следует

**Платный трафик по сегодняшней конверсии убыточен.** Клик в этой нише стоит
$0.30–$1.50 в Meta и $0.50–$3.00 в поиске Google. Порог безубыточности — 12
центов. Промах в 3–25 раз.

**Это проблема конверсии, а не трафика.** 1281 человек прочитали и 4 заплатили.
Удвоение трафика удвоит и расход, и убыток. Поэтому ниже платное — это
эксперименты с порогом остановки, а не масштабирование.

**Рабочий порог для любого платного канала: $2.50 за регистрацию.** Выше $5.2 —
убыток по определению, между ними — работа в ноль.

## 3. Бесплатные каналы

### 3.1. Контент под событие — доказанный движок, приоритет №1

Один материал дал 1281 читателя, 31 регистрацию и первые деньги. Повторять.

**Но сезон триатлона закончился.** Следующий чемпионат мира Ironman 70.3 —
август 2027, Чаттануга. До весны крупных триатлонных поводов нет.

**Дыру закрывает бег.** И это удачно вдвойне: беговая половина продукта почти
не используется (6 анализов против 171), а беговая аудитория на порядок больше
триатлонной.

**Ближайший повод — NYC Marathon, воскресенье 1 ноября 2026, 50-й юбилейный.**
Семнадцать дней. Это прямое продолжение формата: разбор техники бега элитных
бегунов по кадрам трансляции, те же измеренные углы, те же диапазоны.

| | |
|---|---|
| стоимость | время, ~2–3 дня работы |
| публиковать | **29–31 октября**, до гонки, пока ищут контент |
| ожидание | по аналогии 800–1500 читателей, 20–35 регистраций |

Дальше по календарю: Valencia Marathon (декабрь), весенние мейджоры — Токио,
Бостон, Лондон. **Даты подтверждать на официальных сайтах**, в поиске они
расходятся.

### 3.2. SEO как побочный продукт — бесплатно и накапливается

Google уже растёт. Ничего дополнительно делать не нужно — каждая статья под
событие оставляет страницу, которая работает годами. Через полгода это
становится основным каналом, если выпускать регулярно.

Одно техническое: статьи стоит писать так, чтобы их **цитировали языковые
модели** — явный ответ в первом абзаце, таблицы с нормами, ссылки на
исследования. Из ChatGPT уже приходят люди, и это дешевле любого SEO.

### 3.3. Slowtwitch и форумы — 69 человек бесплатно

Статью подхватил forum.slowtwitch.com сам. Это главный триатлонный форум мира,

Дальше — не постить рекламу, а **участвовать**: в `r/bikefit` и на Slowtwitch

| | |

### 3.4. Локальные клубы — всё ещё не начато

Единственный канал, где работает твой главный актив: ты сам триатлет со

единственный путь к B2B (веломагазины, тренеры, физиоклиники — одна такая уже

## 4. Платные каналы

Напоминание: порог **$2.50 за регистрацию**, выше $5.2 — заведомый убыток.
Всё ниже — эксперименты на две недели с жёстким правилом остановки.

### 4.1. Google Search — единственный, где я бы ставил деньги первым

Поиск отличается от соцсетей тем, что человек **уже ищет решение**. Конверсия
с такого трафика в разы выше, чем с холодного читателя статьи, — именно
поэтому 0.31% здесь не ориентир.

| | |
|---|---|
| бюджет теста | **$10/день × 14 дней = $140** |
| запросы | `bike fit app`, `bike fit online`, `running gait analysis app`, `cycling position analysis` |
| не брать | общие `running form`, `cycling tips` — там любопытство, не намерение |
| остановка | цена регистрации выше **$2.50** на 50+ кликах |

**Это самый дешёвый способ узнать правду о платном трафике.** $140 либо
покажут работающий канал, либо закроют вопрос на полгода.

### 4.2. Meta (Facebook/Instagram) — только ретаргетинг, не холодный охват

Холодный таргет в Meta при наших числах убыточен гарантированно. Но Facebook
уже привёл 850 человек органически, и **пиксель их видел**.

| | |
|---|---|
| бюджет | **$5/день × 14 = $70** |
| аудитория | кто читал статью и не зарегистрировался |
| креатив | кадр со скелетом и углами — он уже доказал кликабельность |
| остановка | та же, $2.50 за регистрацию |

### 4.3. Reddit Ads — дешевле, но аудитория хуже платит

| | |
|---|---|
| бюджет | **$100 разово** |
| сабреддиты | r/triathlon, r/Velo, r/bikefit |
| оговорка | Reddit исторически плохо конвертит в оплату; это проверка гипотезы, не канал |

### 4.4. Спонсорство на Slowtwitch / в подкасте — пока нет

Баннер или выпуск стоит $500–3000. При нынешней конверсии это сожжёт месячный
бюджет за неделю без шанса окупиться. **Вернуться, когда цена регистрации из
платного канала станет известна и окажется ниже $2.50.**

### Итого по платному

| | бюджет | что узнаём |
|---|---|---|
| Google Search | $140 | работает ли платный трафик вообще |
| Meta ретаргетинг | $70 | дешевле ли возвращать, чем привлекать |
| Reddit | $100 | есть ли там платящие |
| **всего** | **$310** | **на две недели, с правом всё остановить** |

Это не рекламный бюджет, а **плата за знание**. Триста долларов отвечают на
вопрос, который иначе будет гадательным ещё полгода.
