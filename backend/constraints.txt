# Every package the image installs, at the version it was built and tested
# with -- the transitive ones too. requirements.txt says what we depend on;
# this says exactly what gets installed, so a build next week is the build
# that passed CI today. starlette 1.8.0 arriving unannounced as a transitive
# turned every 304 into a 500 (2026-10-13); this closes that for every one of them.
#
# Used as a constraints file (pip -c): it pins versions but installs nothing
# by itself, so a line for a package nobody needs any more is harmless.
#

# is), then let CI prove it:
